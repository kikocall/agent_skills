# 质量门禁

不管是小批验证还是大批滚动执行，都至少检查下面这些门禁。

## 结构门禁

- DDL 与目标字段一致
- 文件字段顺序与外表定义一致
- 分区目录与分区字段一致
- 编码、分隔符、压缩格式明确

## 关系门禁

- 主键唯一
- 外键可关联
- 维表和事实表的引用值存在
- 桥表没有明显悬挂键

## 业务门禁

- 时间顺序合理
- 状态值合法
- 金额范围合理
- 汇总层与事实层可抽样对账

## 规模门禁

- 单批大小在容量预算内
- 批次数量合理
- 上传窗口和清理窗口可执行
- 热点、长尾、空值率符合设定

## 执行门禁

- 小批数据已成功上传 HDFS
- 小批外表已可读
- 目标 SQL 已可跑通
- 读回结果符合预期

只有通过这些门禁后，才建议进入全量滚动执行。
