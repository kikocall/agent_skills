# 星环交付模式

根据目标环境选择更贴近现场的交付方式。

## ArgoDB 或 HoloDesk

推荐优先级：

1. 本地按批生成文件
2. 上传到 HDFS
3. 建外表映射 HDFS 目录
4. 从外表装载到内表
5. 做读回校验和任务回放

关注点：

- 分布键
- 分区键
- 桶数
- 压缩与装载窗口

## TDH 或 Hive 兼容引擎

推荐优先级：

1. 分区目录规划
2. 文件格式规划
3. 外表读取
4. 分区装载或直接查询

关注点：

- 分区字段是否与目录一致
- 文件格式与压缩格式
- 装载是否需要覆盖或增量

## Quark 相关执行

当需要真实连接或提交执行时，交给 `quark-python` 负责连接和执行，当前 skill 只负责：

- 造数方案
- DDL/SQL 草案
- 批处理编排设计
- 校验步骤
