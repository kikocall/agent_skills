# 外表与目标表判断

先判断外表怎么建，再判断目标表怎么装。

## 外表判断顺序

1. 现场已有外表建表语句
2. 现场已有明确文件格式说明
3. 默认按本地文件格式推断

例如：

- 本地是 txt -> 默认 TEXTFILE
- 本地是 csv -> 默认 csvfile 或现场 csv 外表语法
- 现场直接给了外表建表语句 -> 优先复用现场语句

## 目标表判断顺序

1. 现场目标 DDL
2. 任务 SQL 中对目标表的依赖
3. 推断目标是 holodesk、orc、rcfile 等格式

## 默认装载路线

- 外表映射 HDFS 文件
- 内表按目标 DDL 建表
- 从外表装载到内表
- 再执行下游任务 SQL

## 什么时候不要直接建内表

- 还没确认目标表字段顺序
- 还没确认目标分区字段
- 还没确认目标存储格式
- 现场已有标准建表模板但尚未拿到
