# 文件格式规则

默认先从“本地实际写出的文件格式”出发，再决定外表格式。

## 默认规则

- 本地默认写 `txt`
- 默认编码 `UTF-8`
- 默认换行 `\n`
- 默认采用稳定分隔符，例如 `\001`、制表符或现场指定分隔符
- 默认不写表头，除非现场格式明确要求

## 外表格式优先级

1. 现场已有外表建表语句
2. 用户明确给出的输入文件格式，例如 csvfile
3. 本地默认 txt -> 外表默认 TEXTFILE

## 目标表格式优先级

1. 现场目标 DDL
2. 任务 SQL 依赖
3. 谨慎推断的 holodesk、orc、rcfile 等格式

## 需要写清楚的参数

- 编码
- 字段分隔符
- 行分隔符
- 是否转义特殊字符
- 是否有空值占位符
- 单文件目标大小
- 文件命名规则

## 小批验证要求

small 模式必须先验证：

- 文件字段顺序是否与外表列顺序一致
- 分隔符是否正确
- 空值是否可读
- 特殊字符是否会破坏解析
