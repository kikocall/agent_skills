# HDFS 与装载模式

根据目标表类型决定落地路线。

## 模式一：外表直接映射

适用：

- 目标本身就是外表
- 只需要查询或验证

流程：

1. 数据上传到 HDFS
2. 建外表指向目标目录
3. 直接查询或让下游任务读取

## 模式二：外表中转后装载内表

适用：

- 目标是 ArgoDB 或 HoloDesk 内表
- 需要压缩存储、分布键和装载控制

流程：

1. 数据上传到 HDFS
2. 建外表读取文件
3. `insert into` 或 `insert overwrite` 内表
4. 做读回与行数校验

## 模式三：多分区目录装载

适用：

- 按天、月、机构等分区滚动导入
- 历史和增量共存

流程：

1. 按分区生成目录
2. 上传对应目录文件
3. 外表映射多级目录
4. 分区装载内表

## ArgoDB 侧注意点

- 优先复用现场已有 DDL/SQL 风格
- 明确分区键、分布键、桶数和压缩策略
- 不确定语法时，先标明依据，再给兼容写法
