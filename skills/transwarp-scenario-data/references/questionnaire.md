# 提问清单

目标是“严格提问优先，但不把用户拖进碎片化追问”。

## 必问项

这些问题不确认清楚，就不要假装已经能给正式执行版：

1. 业务域是什么
   - 银行
   - 证券
   - 泛金融
   - 政务
   - 其他
2. 要复现的是什么场景
   - 离线全量
   - 日批
   - 月批
   - 报表
   - 宽表
   - 联调
   - 压测
3. 目标环境是什么
   - ArgoDB
   - HoloDesk
   - Quark
   - TDH
   - Hive 兼容引擎
4. 已有材料是什么
   - DDL
   - SQL 或调度脚本
   - 统计信息
   - 样本数据
   - 暂无
5. 目标规模是什么
   - 单表大小
   - 总数据量
   - 历史周期
   - 日增量
6. 是否有硬规则
   - 主外键
   - 账务一致性
   - 时间顺序
   - 脱敏格式
   - 热点分布

## 强烈建议问

- 本地应用节点可用磁盘多大
- 单批允许生成多大文件
- HDFS 目标路径是否已定
- 是直接外表映射还是外表后再导内表
- 是否需要先做小批验证
- 需要交付到什么深度
  - 方案
  - DDL
  - 脚本骨架
  - 校验 SQL
  - 可执行编排

## 可在信息不足时推断

只有用户明确希望先推进时，才允许推断：

- 典型主题域
- 默认客户与账户比例
- 默认交易长尾分布
- 默认分区字段
- 默认小批验证规模

推断后必须显式区分：

- 已确认事实
- 工作假设
- 待确认风险

## 提问后的整理格式

提问完成后，先整理成：

- 已知信息
- 缺失信息
- 输入等级
- 规模模式
- 是否足够进入正式设计
