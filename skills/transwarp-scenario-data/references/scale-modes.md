# 规模模式

先判断当前任务落在哪个规模档，再决定默认方案。

## 小批验证模式

适用：

- 字段映射验证
- 导入链路验证
- SQL 逻辑验证
- 小样本功能测试

特征：

- 数据量小
- 快速生成
- 快速读回

禁用事项：

- 不要当成 TB 级复现方案
- 不要默认逐条 insert 放大执行

## 中大规模联调模式

适用：

- 需要一定量级的联调
- 需要体现分区、热点、宽表关联

特征：

- 仍然建议走文件批次
- 重点验证链路稳定性

## TB 级复现模式

适用：

- 目标是测试集群映射生产规模
- 单表可能达到数十 GB 到数百 GB
- 总量达到 TB 级

特征：

- 默认走批量文件模式
- 必须显式设计单批大小、单批文件数、HDFS 路径和本地清理策略

## 分布式生成模式

适用：

- 单节点生成吞吐不够
- 本地磁盘和上传窗口都吃紧
- 目标规模继续上升

特征：

- 推荐 Spark、Flink、Treagen、TPC-DS 风格生成
- 数据直接写 HDFS
- 再外表映射或装载入库
